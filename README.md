## Background & Motivation

As a Cognitive Science student, I've always been fascinated by how and why people make decisions. I've spent a lot of time studying the psychological and neurological processes that influence human behavior, but I've also become equally interested in how data can be used to represent those processes in a way that is understandable and actionable.

This project was created as a practical exercise in working with structured data from end to end. I generated a synthetic dataset, exported it as a CSV file, imported it using Python and Pandas, and created visualizations using Matplotlib to explore trends over time.

While the dataset represents simulated brain activity during a Brain-Computer Interface (BCI) motor task, the primary goal of the project was not neuroscientific accuracy. Instead, it was to strengthen my understanding of data processing and visualization workflows and to practice communicating information through clear graphical representations.

---

## Project Overview

This project demonstrates a complete data visualization workflow using Python:

1. Generate structured time-series data.
2. Store the data in CSV format.
3. Load and process the dataset using Pandas.
4. Visualize multiple variables using Matplotlib.
5. Highlight important events within the data to improve interpretability.

The resulting visualization allows users to quickly identify trends, compare activity across variables, and observe changes associated with a simulated task period.
